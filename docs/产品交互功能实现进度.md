# Sprix AI 产品交互功能实现进度

> 日期：2026-06-27
>
> 口径：prompt 只作为产品交互目标参考；当前实现接真实后端，不写前端 mock 数据。后端尚未提供的字段或接口，前端先留空、隐藏或展示正式的“待接口接入”状态。

## 本轮已完成

### C 端入口和准入

- `/` 已从直接跳任务市场改为 C 端入口页。
- 入口页主操作为“连接本地 Agent / 登录后连接 Agent / 进入任务市场”。
- 未登录访问 `/agent/*` 会回到 `/`。
- 已登录但没有后端确认的“当前执行 Agent + 已连接”时，访问 `/agent/*` 会回到 `/`。
- 准入规则只依赖真实账户状态和后端 Agent 列表，不再使用本地评测 localStorage。
- 准入阻断文案已改为“请先连接并设置当前执行 Agent”，不再提示前端本地职业画像或能力评分。
- Agent 中心已作为准入结果展示页，展示后端返回的当前执行 Agent、连接状态、角色、综合评分、能力标签、最近评测时间。
- 后端未返回能力标签或最近评测时间时，Agent 中心展示“能力标签待后端返回”和“待后端返回”，不补前端假标签或假时间。
- Agent 连接按钮和连接成功提示不再写“连接并评测/评测完成”，改为只说明连接 Agent；能力画像和评分以后端返回为准。
- `/local-agent/claim` 页面已展示“绑定完成回跳目标待后端返回”，不在前端硬写绑定成功后的目标页。
- `/local-agent/claim` 生产构建未注入 `VITE_LOCAL_AGENT_CLAIM_BASE_URL` 时，已默认跳转 `http://42.194.150.73:8084` 后端，不回到 8081 前端。
- `apps/sprix-agent` 产品目录下的 mock claim HTML 辅助页已移除，不再保留带 mock token 的本地入口。
- 后端未返回能力维度时，能力画像展示明确空状态，不再展示前端固定维度或推导分。
- 退出登录后回到 `/`，不再回到任务市场。
- README 已从“前端本地状态驱动 Demo / `src/data/mock.ts` 本地模拟”更新为真实后端接口口径，并同步当前 C 端、管理后台路由。

### 任务市场去 Demo 化

- 删除了 `cSideExperience.ts` 和对应测试。
- 任务市场不再展示前端固定 Agent、固定职业画像、固定评分。
- 任务市场不再展示“自动接单演示”“本版不实际接单”“Token 预测”等用户可见文案。
- 任务列表只展示后端已发布任务。
- 推荐/匹配能力已展示待接口状态区；匹配度、推荐理由、推荐团队、推荐排序在真实接口未提供前不展示假结果。

### 任务详情去本地兜底

- 接单确认只认后端当前执行 Agent。
- 不再用本地评测结果兜底显示“本地已连接”。
- 移除了任务详情中前端固定的“适配度”“Agent 匹配分析”“推荐执行团队”展示。

### 前端假值降级

- Agent 端和 Admin 端 task adapter 中固定的 `agentMatchScore: 92` 已降为 `0`，且当前 UI 不展示。
- 固定的 `suggestedTeam`、`matchAnalysis`、`recommendedReason` 已改为空。
- 验收未通过的固定 `72/100` 分数已移除。
- 管理后台完成记录分数改为使用后端 `agentScore`，没有则展示 `-`。
- 支付宝绑定不再硬编码 `verifiedName: "Xiaoxiao"`，改为用户填写认证姓名后提交。
- Agent 能力画像不再由前端根据综合分推导；后端未返回标准维度前，前端展示空状态。

### 管理后台审计追溯

- 任务详情已接出后端 `operationLogs`。
- 任务详情页新增“操作记录”模块，展示操作、变更前、变更后、原因/备注和时间。
- 任务详情页执行记录中的“查看执行详情/结果/验收详情/申诉/结算”已改成禁用的待接口动作，不再展示无真实目标的可点击按钮。
- 管理后台任务发布、编辑、下线、重新发布和删除已按后端 dev Swagger 接入真实写接口。

### 接单资格和我的任务动作

- 从任务接单弹窗进入接单资格页时，开通成功后会回到原任务详情继续接单。
- 没有来源任务时，开通成功后仍回到任务市场。
- 实人认证入口已改为只初始化后端认证会话；后端返回 `webUrl` 时跳转真实认证页，未返回时提示待后端返回，不再由前端直接调用完成认证接口并展示成功。
- 我的任务按钮已按现有后端能力区分：验收未通过可申诉/重新执行，申诉处理中显示只读状态，已终止可重新执行，结算中/已结算显示“查看验收结果”。
- 重新执行已增加二次确认；用户主动终止执行已展示禁用的待接口入口，不发起假请求。
- 申诉提交弹窗不再承诺固定 `1-3 个工作日` 处理时效，处理进度以后端返回状态和时限字段为准。

### 报酬结算真实口径

- 报酬结算页已展示真实可提现金额、提现账户卡片、实名一致性状态和提现入口。
- 有本次提现后端返回记录时展示记录；没有记录时明确提示历史提现记录查询接口待接入。
- C 端结算明细没有查询接口时展示待接入空状态，不再把空数组表现成完整明细。
- 提现审核/打款进度刷新已展示禁用的“刷新打款进度（待接口）”入口，不伪造状态流转。
- 账户昵称缺失不再补 `Xiaoxiao`，提现预计到账时间缺失不再补固定 `1-3 个工作日`。
- 提现弹窗不再使用演示支付宝账号兜底，预计到账时间改为以后端返回为准。
- 提现账户绑定后的提示文案和提现申请弹窗实名一致性摘要已按后端实名匹配状态展示；后端返回不匹配时不再提示“实名一致性已通过”。
- 提现入口已按真实账户状态阻断：无可提现金额、未绑定支付宝或实名一致性待确认时，不直接提交提现申请。
- 已绑定支付宝后不再直接开放更换；页面提示需要手机号验证码安全验证接口接入后再更换。
- 管理后台资金中心结算记录的“查看详情”已改成禁用待接口动作，不再展示无真实目标的可点击按钮。
- 管理后台待打款页“导出打款清单”已改成禁用待接口动作，不再由前端生成正式打款 CSV 文件。
- 管理后台提现审核和待打款的批量操作已改成禁用待接口动作，不再调用 Swagger 未提供的 `bulk-*` 手写路径。

### 执行详情真实口径

- 我的任务详情页已补执行概览卡：执行状态、当前节点、执行进度、结算状态、执行 Agent、任务奖励。
- 任务要求只拼接后端真实返回的任务描述、交付标准、验收标准。
- 后端未返回验收结果、执行日志、交付文件或验收附件时，页面显示明确待接口空状态。
- 同任务历史执行、执行日志、结算明细已展示独立待接口空状态，不写本地模拟记录或估算金额。
- Agent 端和 Admin 端任务 adapter 不再为缺失的 title、sourceName、deliverables、acceptanceCriteria、acceptanceResult 补固定文案。
- Agent 端和 Admin 端任务 adapter 不再为缺失的 category、sourceType 补“未分类/平台任务”；下线原因不再把未知后端原因改写成“手动下线”，仅对明确的名额已满枚举做展示翻译。
- Agent adapter 不再为缺失的 Agent 名称、最近评测时间、能力摘要补 `Unnamed Agent`、`未有记录` 或固定摘要；页面层按待后端返回状态展示。
- 管理后台执行记录不再为缺失进度补 `0%`，不再为缺失终止原因补“执行终止”，统一展示真实字段或占位。

### 接单资格记录真实口径

- 接单资格页已新增资格记录模块，展示账户接口返回的接单资格、实人认证和服务协议状态。
- 认证主体、认证时间、协议版本、签署时间未由后端返回时，页面显示“待后端返回”，不写前端假记录。

### 账户信息真实口径

- 账户信息弹窗只展示账户接口返回的昵称、邮箱、手机号、接单资格和提现账户状态。
- 修改头像、修改昵称、修改手机号、注销账户已展示为待接口接入动作，不做本地假保存或假注销。

### 协议内容真实口径

- 相关协议弹窗已明确展示“正式协议全文待接入”。
- 当前用户协议、隐私协议和自由职业者服务框架协议只保留产品流程摘要，不把它标记为正式法务全文。

### 联系方式真实口径

- 联系我们弹窗不再展示固定客服电话 `400-800-1024` 或固定服务时间。
- 客服渠道、服务时间和问题分类已展示为待运营配置/后端接口接入。

### 智能接单真实口径

- 智能接单入口保留，弹窗展示当前执行 Agent、待接口状态和禁用的开启/保存阈值/查看命中结果动作。
- 后端未返回智能接单配置前，不再展示固定阈值或本地开关。

### 职业画像编辑真实口径

- Agent 中心已展示“编辑职业画像（待接口）”禁用入口。
- 职业画像读取、编辑和保存接口接入前，不做前端本地假保存。

### 预计 Token 真实口径

- C 端任务卡和任务详情已展示“预计 Token 待后端字段接入”。
- C 端我的任务列表和执行详情已展示“预计 Token 待后端字段接入”。
- 管理后台发布/编辑任务页已展示只读的预计 Token 待字段说明，提交 payload 不包含本地估算值。
- 管理后台发布新任务表单在写接口接入前不再预填“平台任务”来源类型。

### 后台登录真实口径

- 管理后台登录页已明确展示“后台登录接口待正式接入”。
- 当前后台登录仍调用 `/api/v1/auth/mock-admin-login`，前端不把它标记为生产登录。
- 登录表单和登录服务函数不再预填或隐式使用 `admin@sprix.ai / 123456` 这类 mock 凭证。
- 登录流程本身未改动，等后端提供正式管理员登录接口后再替换。
