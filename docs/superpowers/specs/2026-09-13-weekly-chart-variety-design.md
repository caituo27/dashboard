# 周经营图表差异化设计

## 目标

在不改变 Excel 5.1 数据、日期范围和 Hover 明细口径的前提下，让四张周经营图分别表达量级对比、比例变化、费用构成和质量分布。

## 图表映射

- 周验收 GMV 与同周有效 Agent：绿色 GMV 柱状图叠加蓝色有效 Agent 折线，保留双纵轴。
- 周度异构 Agent 比例：绿色单系列柱状图，纵轴继续显示百分比。
- 近六周待结算费用趋势：每周一根堆叠柱，绿色表示纯 Agent，蓝色表示人 + Agent，共用人民币纵轴。
- 各类型质检通过率：任务类型为行、统计周为列的热力矩阵；颜色深浅表达通过率，空值显示为浅灰色。

## 交互与响应式

所有图继续使用现有紧凑白底 Tooltip，并展示当前节点完整数据。图表布局与窄屏上下排列规则保持不变。
