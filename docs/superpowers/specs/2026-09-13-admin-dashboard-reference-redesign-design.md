# Sprix 核心经营看板参考图改版设计

## 目标

在不改变 Excel 5.1 统一经营数据模型、日期筛选、任务下钻和订单弹层的前提下，将当前纵向表格堆叠式 Dashboard 重组为参考图中的浅色经营驾驶舱。

## 视觉方向

- 页面使用浅蓝灰背景、白色内容面板、细描边和轻量阴影，主色保持 Sprix 青绿色，并用蓝色、天蓝和琥珀色区分辅助数据。
- 侧边栏保持现有真实路由，不补造不存在的菜单；当前菜单改为浅薄荷绿选中态。资金管理中心继续隐藏。
- 圆角控制在 8–12px，不使用渐变、发光或大面积深色块。
- 数字使用更强字号和字重，解释性文案弱化，避免所有模块视觉权重相同。

## 页面结构

1. 页头：标题改为“Sprix 核心经营看板”，保留日期范围、统计截止时间和刷新数据。
2. 核心指标：拆成两个明确口径组。第一组为“所选期间”，展示新增 Agent、验收 GMV、Agent 交付任务数；第二组为“最新统计周”，展示异构性 Agent 占比、有效 Agent 数、有效 Agent 周均贡献 GMV。两个分组并排展示，窄屏时上下排列。
3. 经营概览：左侧展示每日新增 Agent 柱状图与周度异构性阶梯线，右侧使用双坐标轴折线展示周验收 GMV 与有效 Agent。
4. 任务履约与结构：每日交付任务和有效 Agent 使用完整宽度展示；任务主记录、总名额、执行记录、剩余名额独立成为“截至数据统计日的平台规模”快照条，不受查询开始日期影响。Agent 自动交付金额、人工上传交付金额属于相交整周金额，保留在结算区域。
5. 类型分布分析：左侧展示纳入周内、按所选日期过滤后的新增 Agent 类型绝对值堆叠条形图，所有周共用同一数量刻度，条长表示新增数量、颜色表示类型构成；右侧按所选日期汇总任务类型交付量并降序排列，任务类型保持可点击下钻。
6. 质量与收入结构：左侧为各类型周交付金额表，中间为各类型质检通过率趋势，右侧为自动交付、人工上传两类待结算费用卡。

## 数据与交互约束

- 不修改 `BusinessMetrics` 数据接口及 Excel 5.1 Mock 计算逻辑。
- 发单任务类型金额之和继续严格等于周验收 GMV。
- 每日交付任务数继续大于等于每日有效 Agent 数。
- Agent 自动交付金额和人工上传金额、两类待结算费用继续沿用已确认公式。
- GMV 卡点击打开订单明细；任务数、任务主记录及类型任务条点击进入任务管理中心。
- 日期筛选和刷新按钮保持原行为。
- 选择 2026-09-07 至 2026-09-12 时展示明确无数据状态，不向 2026-09-06 统计截止日之后补造数据。
- 查询切换不保留上一范围占位数据，页头筛选器在加载态继续可用，请求通过 AbortSignal 处理竞争。
- 日期控件是“查询日期范围”，不是日/周切换器。页面通过“所选日期累计”“相交整周”“截至统计日”三个标签区分指标口径。
- 平台规模只有 2026-09-06 的可靠快照，因此在所有可选范围内固定展示该快照；不根据任意开始日期反推历史剩余名额。

## 响应式

- 宽屏保持参考图的双列/三列信息密度。
- 中等宽度下 KPI 改为三列、内容区改单列。
- 移动端 KPI 和图表改单列，横向金额表允许滚动，图例和标题自动换行。
