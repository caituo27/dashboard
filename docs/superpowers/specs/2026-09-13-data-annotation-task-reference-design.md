# 数据标注任务参考数据统一设计

## 目标

使用用户提供的 31 条数据标注任务作为内容与数值层级参考，更新 Excel 5.1 的“任务清单样例”和 Sprix Admin mock。Excel 5.1 的任务、名额、执行、验收 GMV 与结算控制数保持不变。

## 基准与约束

- 任务主记录：10,834 条。
- 发布总名额：18,370 个。
- 执行记录：16,251 条。
- 剩余名额：2,119 个。
- 累计验收 GMV：1,699,400 元。
- 任务金额始终满足：`任务总金额 = 人均金额 × 总名额`。
- 参考数据的原始金额和名额不直接覆盖控制数，只用于判断任务的相对价值与规模。
- 参考数据中“审计领域大模型训练数据集采集与标注”的总金额、人均金额和名额不守恒。生成结果不继承该冲突，以现有分配结果重新计算总金额。

## 内容模板

新增一份共享的数据标注任务模板源，保存 31 条参考任务的以下字段：

- 任务名称
- 详细任务描述
- 交付标准
- 验收标准
- 来源任务总金额
- 来源人均金额
- 来源总名额

原始数值只作为模板排序和匹配权重，不作为平台经营数据。重复的“物流与工业工程领域 ALE 任务包设计”保留一份基础模板，生成任务时通过批次号区分具体记录。

## 生成规则

### 模板匹配

数据标注任务按现有任务索引确定性选择模板。前 31 个数据标注样例按参考表原始顺序完整覆盖 31 条任务；后续记录按来源人均金额、来源总名额和来源任务总金额形成价值与规模层级，并在同层级内通过稳定索引分散选择。

同一个任务索引在多次启动、分页、筛选和详情查询中必须得到相同模板。任务名称使用参考名称；同一模板再次出现时追加稳定批次号，避免列表出现无法区分的同名记录。

### 数值规则

- 总名额继续使用现有 5.1 名额分配结果。
- 人均金额继续使用现有经营与结算链路的分配结果。
- 任务总金额由人均金额和总名额计算，不读取参考任务总金额。
- 参考金额与名额只影响模板和现有任务之间的高低层级匹配。
- 预计消耗 Token 继续按现有确定性规则生成。参考数据该字段为空，不补造原始值。

### 内容字段

- `category` 固定为“数据标注”。
- `sourceType` 延续现有平台发布口径。
- `title`、`description`、`deliverables`、`acceptanceCriteria` 使用参考模板。
- 附件名称参考模板内嵌的 ALE 规范、CTF SOP 和 CVE 可交付清单生成；mock 详情返回附件元数据，并提供可下载的轻量参考摘要、JSON 或 CSV，不复制原模板中的大体积 OLE 二进制。
- 执行结果和验收摘要继续从任务内容派生，确保列表、详情、执行记录与验收记录使用同一任务描述。

## Excel 更新

以最新的 Excel 5.1 后端接口字段版为输入，更新“任务清单样例”中的数据标注任务：

- 保持表头、表格样式、任务编号、日期、分页、手机号池和是否纳入经营汇总等结构不变。
- 使用与 mock 相同的模板选择规则更新任务名称、详细任务描述、交付标准、验收标准和附件名称。
- 金额、Token、总名额、剩余名额与执行记录数继续使用现有控制结果。
- 非数据标注任务保持不变。
- 输出新的工作簿副本，不覆盖原文件。

## Mock 更新

- 将 31 条参考任务整理为共享模板源。
- `business-scenario.mjs` 中所有数据标注任务改用共享模板生成内容。
- `demo-ledger.mjs` 中最新任务的工业级数据标注覆盖逻辑改用同一模板源，不再只使用“大模型语料标注、计算机视觉标注、代码数据标注”三个泛化名称。
- `business-metrics.mjs` 的 Excel 5.1 业务快照任务也使用共享模板，并在任务详情返回对应输入附件。
- `server.mjs` 提供只读的任务输入附件下载路由；执行结果附件仍使用原有独立路由。
- `admin-views.mjs` 继续读取 ledger，不新增独立硬编码数据源。
- 不修改 API、Swagger、路由、身份认证和生产数据。

## 异常与兼容

- 空描述、交付标准或验收标准不进入模板池。
- 参考数字无法守恒时，只保留其层级权重，不覆盖平台数值。
- 当前任务补丁、用户创建任务和既有编辑记录继续优先于生成模板。
- 搜索、分类筛选、分页和详情查询继续使用当前任务 ID 与索引，不改变排序。

## 验证

- 检查共享模板数量、字段完整性和重复标题处理。
- 检查相同任务索引重复生成结果一致。
- 检查数据标注任务使用参考名称和内容，非数据标注任务不变。
- 检查 `任务总金额 = 人均金额 × 总名额`。
- 检查 10,834、18,370、16,251、2,119 和 1,699,400 五项控制数不变。
- 检查 Excel“任务清单样例”与 mock 的同编号任务内容一致。
- 检查 Excel 原有工作表、公式和非目标区域未被改动，并渲染目标区域确认可读性。
- 按项目规则，不运行单元测试、集成测试、Playwright 或浏览器自动化；使用模块语法检查、静态数据检查、工作簿公式错误扫描和视觉检查。
