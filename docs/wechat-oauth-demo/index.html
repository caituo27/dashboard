公众号 OAuth Demo
前端只拿 code，openid 必须后端换取

拉起公众号授权，拿到微信回跳 code

这个单页 demo 只演示 H5 前端流程：填写公众号 AppID 和回调地址，生成微信 OAuth 地址并跳转。 微信回跳后，页面会解析 URL 里的 code 和 state。下一步需要后端用 code + appsecret 换 openid。

1

配置网页授权域名

在微信公众号后台配置当前页面所在域名。redirect_uri 必须落在这个域名下。

2

跳微信 OAuth

前端拼接 open.weixin.qq.com 授权地址，用 snsapi_base 静默拿 code。

3

后端换 openid

前端展示 code；真实项目由后端调用 access_token 接口换 openid 并绑定用户。

必须是服务号/订阅号等公众号 AppID，不是微信支付商户号。
必须 URL encode 前的完整 HTTPS 地址。本 demo 默认填当前页面去掉 query/hash 后的地址。
用于防 CSRF 和记录回跳来源。线上建议后端生成并校验。
这个页面不能直接得到 openid。把 appsecret 放到 HTML/JS 里会泄露密钥，正式项目必须由后端换 openid。
