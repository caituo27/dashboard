# 本地联调与验收约定

最后更新：2026-06-29

## 本地端口

- C 端用户站点默认端口：`5173`
- 管理后台默认端口：`5174`
- 本地后端默认端口：`8084`
- Local Agent 本机服务端口：`8765`

本项目 C 端本地联调以 `http://127.0.0.1:5173/` 为准，不使用临时端口作为默认验收地址。

## 本地后端代理

C 端开发服务需要通过 `/sprix-api` 代理到后端。联调本地后端时，启动前端时应显式指定：

```bash
VITE_API_PROXY_TARGET=http://127.0.0.1:8084 pnpm exec vite --host 127.0.0.1 --port 5173
```

Local Agent 绑定回跳也应指向 `5173`：

```bash
--sprix.local-agent.claim-url=http://127.0.0.1:5173/local-agent/claim
--sprix.local-agent.claim-success-url=http://127.0.0.1:5173
```

## 验收边界

Codex 可以通过命令行、接口请求、编译和类型检查验证代码改动，但不要替用户刷新浏览器页面做最终运行态确认。

涉及浏览器页面最终观感、登录态、弹框状态、用户手动操作后的结果时，由用户自己在浏览器中确认。Codex 如需说明验证状态，应明确区分：

- 已验证：接口、编译、类型检查、端口、进程、服务健康检查。
- 待用户确认：浏览器页面刷新后的实际观感和交互结果。
