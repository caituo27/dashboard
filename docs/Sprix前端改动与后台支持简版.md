# Sprix 前端改动与后台支持简版

更新日期：2026-07-01

## 本次前端已改

1. 管理端资金中心
   - 结算记录、提现审核、待打款、打款异常补了“查看详情”。
   - 当前详情弹窗先展示列表已有真实字段，不造假详情数据。

2. 管理端任务详情
   - 操作日志补“操作人”列。
   - 操作类型、变更前、变更后做中文映射，例如 `UPDATE_TASK` -> “编辑任务”、`PUBLISHED` -> “已发布”。
   - `currentNode` 支持大小写兼容，`generating`、`GENERATING_RESULT` 等展示为“生成结果”。

3. 管理端执行记录
   - 执行中按钮改为：查看执行详情、查看 Agent 信息。
   - 已终止按钮改为：查看执行记录、查看用户信息、查看 Agent 信息。
   - 非验收失败记录不再展示“未申诉”标签。

4. C 端接单资格
   - 账户信息里的“接单资格”增加入口，可直接跳转到 `/agent/qualification`。
   - 接单资格仍按人脸核验 + 协议签署判断。

5. C 端人脸核验
   - 完成确认时会把本次会话的 `certifyId` 传给后端。
   - 避免只读账号旧状态导致“没扫码就通过”。

6. C 端支付宝绑定
   - 绑定状态轮询兼容 `COMPLETED / SUCCESS / SUCCEEDED / AUTHORIZED / BOUND`。
   - 成功后主动刷新提现账户状态。

7. Agent 评测弹窗
   - 初始进度从 `1/6` 开始展示，不再默认卡到 `2/6`。

8. 文档
   - 同步更新了产品实现进度和差异清单里过期的“待接口”描述。

## 需要后台支持

1. 人脸核验
   - `real-person-complete` 需要明确接收并校验 `certifyId`。
   - 或提供按 `certifyId` 查询核验状态的接口。

2. 支付宝绑定
   - 绑定会话轮询接口需要返回稳定终态。
   - 授权成功后需要能立刻读到提现账户。
   - 支付宝风险提示需要后端/支付宝配置正式域名或白名单。

3. Local Agent 在线状态
   - 后端需要返回更明确的 WebSocket、lastSeen、pendingCommand、ready device 状态。
   - 解决页面显示已连接但接单时报 `Current execution agent is not available` 的问题。

4. Agent 评测进度
   - 后端需要返回真实六步进度或最终状态。
   - 前端不伪造 3-6 步进度。

5. 管理端详情接口
   - 需要执行详情接口。
   - 需要用户详情接口。
   - 需要 Agent 详情接口。
   - 需要执行结果、验收报告、结算详情接口。

6. 操作日志
   - 后端需要完整记录创建、编辑、下线、重新发布、删除、审核、资金等操作。
   - 每条日志建议统一返回操作人字段。

7. 接单资格记录
   - 需要返回认证主体、认证时间、协议版本、签署时间、正式协议内容。

8. C 端收益结算
   - 需要历史提现记录接口。
   - 需要结算明细接口。
   - 需要提现审核/打款进度刷新接口。
