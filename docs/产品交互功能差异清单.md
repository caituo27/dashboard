# Sprix AI 产品交互功能剩余清单

> 日期：2026-06-27
>
> 口径：prompt 只作为 demo 演示参考；这里只看产品交互功能。实际实现以真实后端接口为准，不要求前端模拟扫码、localStorage 闭环、假推荐、假 Token 预测或纯 demo 流程。两个站点分开是当前正确实现。

## 当前不再列为问题

- C 端用户站点和管理后台分开两个站点。
- C 端 `/` 已作为入口页，不再直接进任务市场。
- `/local-agent/claim` 已先走 8081 前端 SPA，由前端检查登录并生成 `enrollmentToken`，再跳转 8084 后端 claim。
- 生产构建未注入 `VITE_LOCAL_AGENT_CLAIM_BASE_URL` 时，claim 跳转也默认使用 `http://42.194.150.73:8084`，不回到 8081 前端。
- `apps/sprix-agent` 产品目录下的 mock claim HTML 辅助页已移除，不再保留带 mock token 的本地入口。
- C 端登录使用微信扫码/短信登录的真实接口方向，不再按 prompt 做模拟扫码。
- LocalCLIAgent 绑定流程按真实 `claimToken -> enrollmentToken -> 8084 claim` 路径。
- 正式功能准入提示只要求后端返回“已连接的当前执行 Agent”，不再提示需要前端本地职业画像或能力评分。
- 任务市场不再使用前端本地 Agent 评测、固定画像、固定评分和 localStorage 准入。
- 任务市场不再展示“自动接单演示”“本版不实际接单”“Token 预测”等 demo 文案。
- Agent 连接按钮和连接成功提示不再写“连接并评测/评测完成”，只表达连接 Agent；能力画像/评分以后端返回为准。
- 推荐/匹配/预计 Token 在真实接口未提供前不展示假值。
- 任务 category、sourceType、未知 offlineReason、Agent 名称、Agent 评测时间、执行进度和终止原因不再由前端补固定假文案；缺字段时展示空值、占位或待后端返回状态。
- 提现账户、账户资料、接单资格、申诉、任务执行等流程已尽量使用现有真实接口；缺字段时展示待接口状态。
- 提现账户绑定成功提示和提现申请弹窗里的实名一致性均按后端实名匹配状态展示；后端返回不匹配时不再提示“实名一致性已通过”。
- 实人认证不再由前端直接调用完成接口并显示成功，只启动后端认证会话并跳转后端返回的认证页。
- 管理后台任务发布、编辑、下线、重新发布和删除已按后端 dev Swagger 接入真实写接口。
- 管理后台发布新任务表单不再预填“平台任务”作为来源类型，写接口接入前不提交本地默认来源。

## P0：主链路仍缺

### 1. 智能接单真实状态机

当前状态：

- 前端保留“智能接单”正式入口。
- 弹窗展示当前执行 Agent 和待接口状态。
- 开启、关闭、阈值保存、查看命中结果等按钮为禁用待接口状态。
- 前端不再展示本地假开关、固定阈值或自动接单假结果。

还缺：

- 开启/关闭接口。

- C 端任务卡、任务详情、我的任务、执行详情都只展示“预计 Token 待后端字段接入”。
- 管理后台发布/编辑任务页展示只读待字段说明。
- 管理后台提交 payload 不再包含前端估算值。
- 前端不再用本地规则估算 Token。

还缺：

- 任务实体和任务 DTO 增加预计 Token 字段。
- 管理后台发布/编辑接口接收并校验预计 Token。
- C 端任务列表、详情、我的任务、执行详情返回同一字段。
- 如果需要自动估算，还需要独立 Token 估算接口。

### 3. 推荐/匹配能力

当前状态：

- 任务市场展示推荐/匹配待接口状态区。
- 匹配度、推荐理由、推荐排序、推荐团队当前不展示假数据。
- 前端 adapter 中固定匹配分已降为 `0`，当前 UI 不展示。

还缺：

- 推荐任务接口或任务列表中的推荐字段。
- 匹配度。
- 推荐理由。
- 推荐排序。

## 仍需特别标记的非真实/待确认点

- 后台登录仍使用 `/api/v1/auth/mock-admin-login`，上线前必须替换或确认生产禁用策略。
- 生成的 swagger 中仍包含 `mock-login` 和 `mock-admin-login`，C 端当前登录流程没有使用 mock-login，但后台登录仍待替换。
- 产品 app 目录不再保留 mock Local Agent claim 页面；真实联调应由 LocalCLIAgent 打开 `/local-agent/claim?claimToken=...` 后生成 `enrollmentToken` 并跳转 8084。
- C 端短信登录、Local Agent enrollment、后台任务聚合/详情、后台申诉详情当前是手写 HTTP 调用，不在生成的 Swagger 客户端里；它们需要后端补 Swagger 或明确接口契约。
- 智能接单当前只展示待接口状态，不会真实开启或自动接单。
- 推荐/匹配和预计 Token 当前都不展示假数据，等待真实接口接入。
- 管理后台任务发布、编辑、下线、重新发布和删除已按后端 dev Swagger 接入真实接口。
- Agent 能力维度、能力标签和评测时间仍需后端给标准口径。
- C 端历史提现、结算明细、执行日志、交付文件、验收报告、同任务历史执行仍缺查询接口。
- 管理后台打款清单导出仍缺后端接口，当前不由前端生成正式 CSV。
- 管理后台提现审核和待打款批量操作仍缺后端接口，当前不调用前端手写 `bulk-*` 路径。

- 接单资格记录的主体、时间、协议版本和签署时间仍缺字段。
- 实人认证完成后的回跳、回调或状态刷新口径仍待确认；当前不再前端直接标记成功。
- 账户资料编辑和注销仍缺接口。
- 协议弹窗当前不是正式法务全文。
- 联系我们弹窗当前没有真实客服配置。
- 申诉处理时限当前没有后端字段。
